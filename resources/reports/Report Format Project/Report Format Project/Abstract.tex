\chapter*{Abstract}
\addcontentsline{toc}{chapter}{ABSTRACT} % to add abstract to table of contents
\begin{spacing}{1.5}
Small-to-medium enterprise (SME) retail businesses, particularly local grocery and retail stores, operate under constrained profit margins where inventory miscalculations impose severe financial penalties. Traditional retail management relies heavily on manual ledgers or subjective merchant intuition, leading to costly stockouts of high-velocity goods alongside capital lockup from over-ordering slow-moving lines. While commercial Enterprise Resource Planning (ERP) platforms (such as SAP S/4HANA and Oracle NetSuite) offer enterprise inventory optimization, their steep licensing fees, complex manual parameterization, and persistent cloud-bandwidth dependencies make them fundamentally impractical for independent local merchants.

To resolve this operational dilemma, this project introduces \textbf{NexusERP}, an intelligent, lightweight, edge-first ERP system tightly coupled with an automated Multi-Model AI Demand Forecasting Engine and an automated replenishment pipeline. Designed to execute entirely offline on commodity hardware, NexusERP features a responsive three-tier architecture comprising a modern React 19 Single Page Application, an asynchronous FastAPI application gateway, and an ACID-compliant local SQLite relational core. 

The algorithmic core of NexusERP integrates a mathematical \textbf{Syntetos-Boylan Classification (SBC)} module that analyzes discrete transaction histories via Average Demand Interval ($ADI$) and Squared Coefficient of Variation ($CV^2$) to segment inventory stock-keeping units into Regular, Erratic, Intermittent, and Lumpy quadrants. This mathematical clustering prunes the model candidate search space and dynamically dispatches an automated forecasting tournament pitting Facebook Prophet, Holt-Winters Exponential Smoothing, Random Forest Regressors, Gradient Boosting, and Simple Exponential Smoothing (SES) against one another across out-of-sample holdout test splits, autonomously selecting the minimum Mean Absolute Error (MAE) model per item.

Furthermore, predicted demand vectors are directly translated into physical procurement operations via a scientific periodic $(s, S)$ replenishment policy, calculating dynamic Safety Stock ($SS$), Reorder Points ($ROP$), and 7-day restocking volumes. Integrated with an atomic Point of Sale (POS) checkout supporting 80mm thermal receipt generation, a 4-stage Purchase Order lifecycle, and an ABC-XYZ inventory matrix, NexusERP provides small retailers with a self-contained, enterprise-grade inventory intelligence platform. In this Phase~I work, the comprehensive system design, database architecture, multi-model forecasting pipelines, POS checkout core, and initial empirical validations across 30 fast-moving retail categories are established and verified.
\end{spacing}
